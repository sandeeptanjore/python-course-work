### 1. find() and index() Methods

Given: `s = "Python Programming is fun"`

1. Find the position of `"Prog"` using `find()`.
2. Find the position of `"fun"` using `index()`.
3. What happens if you use `find()` for a substring that doesn't exist? Write code to show it.
4. What happens if you use `index()` for a substring that doesn't exist? Write code to show it.
